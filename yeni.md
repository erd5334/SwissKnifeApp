Yeni Modül Önerileri
🎯 Öncelik 1 - Hemen Eklenebilecek Popüler Modüller
1. 🌐 Network Araçları (Network Tools) ⭐⭐⭐
Neden önemli: IT profesyonelleri ve power user'lar için vazgeçilmez.

Özellikler:

✅ Ping Tester - Hem single hem bulk IP ping
✅ Port Scanner - Açık port kontrolü (1-65535)
✅ IP Lookup - Geolocation, ISP bilgisi, Whois
✅ DNS Lookup - A, MX, CNAME, TXT kayıtları
✅ Subnet Calculator - CIDR hesaplama
✅ MAC Address Lookup - Vendor bilgisi
✅ Traceroute - Route visualization
✅ Network Speed Monitor - Bandwidth kullanımı
Kullanılacak Kütüphaneler:

System.Net.NetworkInformation
DnsClient.NET
MaxMind.GeoIP2 (IP geolocation)
2. 🔍 Duplicate File Finder (Yinelenen Dosya Bulucu) ⭐⭐⭐
Neden önemli: Disk alanı tasarrufu, dosya organizasyonu.

Özellikler:

✅ Hash-based karşılaştırma (MD5, SHA256)
✅ Boyut + isim karşılaştırma
✅ Görsel karşılaştırma (perceptual hash)
✅ Toplu silme/taşıma
✅ Disk alanı kazanç hesaplama
✅ Excelden yinelenen satır/sütun bulma
3. 📝 Regex Tester & Builder ⭐⭐
Neden önemli: Geliştiriciler için sürekli ihtiyaç duyulan araç.

Özellikler:

✅ Regex test editörü (syntax highlighting)

✅ Replace önizleme
✅ Common patterns kütüphanesi (email, phone, URL)
✅ Regex cheat sheet
✅ Regex generator (email, phone için otomatik)
✅ Performance testi
4. 📸 Screen Capture & Recorder ⭐⭐⭐

✅ Full screen capture
